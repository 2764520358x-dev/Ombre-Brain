# 记忆工具（Ombre Brain MCP）

- `breath()` — 每次对话开始，读取最重要的记忆
- `hold(content)` — 记住重要的事
- `grow(content)` — 更新或深化记忆
- `trace(query)` — 搜索具体记忆
- `dream()` — 整理记忆
